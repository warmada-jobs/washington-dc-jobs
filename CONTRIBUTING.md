# Contributing

This list is generated by [Warmada](https://warmada.com) from public job boards. Do not edit README.md by hand: the next daily update overwrites it, and pull requests that change it are closed.

To report a bad listing (closed, not in the US, in the wrong category, or not a real job), email hello@warmada.com with the company, the role and what is wrong. We fix the rule that put it there, not just the row.

The same data is available as JSON at https://warmada.com/lists/washington-dc.json.
